# Construction

Esta pasta contem os artefatos canonicos da fase CONSTRUCTION do AI-DLC.

## Estrutura

- `plans/`: planos de geracao e execucao por unidade.
- `{unit-name}/functional-design/`: desenho funcional por unidade.
- `{unit-name}/code/`: resumo de codigo gerado e arquivos alterados.
- `build-and-test/`: instrucoes, execucoes e resultados de validacao.
